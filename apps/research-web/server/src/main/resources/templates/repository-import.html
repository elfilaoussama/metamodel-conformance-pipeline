Acquisition limits and unsupported inputs

120 s acquisition budget; 256 MiB acquired Git data by default; up to 2,000 selected files, 64 MiB total, 2 MiB per file. These are operational limits. Symlinks, submodules, unresolved LFS pointers and unsafe/non-portable paths in the selected source are rejected explicitly. Content is read from Git blobs without checkout filters or archive exclusions. File modes are recorded; executable permissions are not applied.
