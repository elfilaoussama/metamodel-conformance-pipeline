# Python native evidence — adapter 0.10.0 / schema 14

One SOURCE_ONLY source-declaration domain covers the captured AST population.
Its configuration binds the bridge script, reported interpreter version, normalized
declared distribution/version/digest and import-attribution metadata, ambiguous
modules and sorted boundary hints. The input digest additionally binds source-unit
bytes. Physical origins stay in paths/lines; canonical declaration IDs are qualified
with this measurement context. The virtual `python-context/ast-declarations` unit
records the normalized configuration hash.

This is not runtime import/MRO observation, selected-build success or closed
interpreter/runtime provenance. Source snapshots remain byte-bound; environment,
support/generated roles and fresh-source reproducibility remain separate obligations.

Ordered direct-base occurrences survive as native evidence while fixed P0 still
uses its unordered graph. Unique source bindings resolve to contextual classifier
IDs. Builtin roots outside that population, opaque dependencies and unresolved
bindings retain occurrences with unavailable targets. Boundary hints cannot promote
hierarchy completeness. Python access/virtuality are NOT_APPLICABLE.

Supported method parameters carry SOURCE_ANNOTATION meaning. Native declared return
annotations also carry SOURCE_ANNOTATION; annotations never become runtime types
or a METHOD_RETURN_TYPES claim. Receiver CV/ref qualifiers are a known empty
inapplicable sequence. Unannotated/unsupported parameter or descriptor subsets are
UNSUPPORTED, distinct from known zero-parameter signatures. Existing completeness
gates remain unchanged. Scope/abstraction describe supported source declarations;
runtime lookup, body/binding, override and role receipts are not invented.

Legal abstract static methods with callable bodies remain possible fixed-P0
disagreements. Extractors do not decide their conformance. Schema 14 preserves both
the native receipts and the existing explicit projection; frozen producers retain
their historical interpretations.
